相関と独立

確率変数が複数の場合

ここまでは主に 1 つの確率変数とその分布を扱ってきたが，現実の問題では 2 つ以上の確率変数を同時に観察することが多い。たとえば，「ある学生の身長 \(X\) と体重 \(Y\)」「あるユーザの年齢 \(X\) とサイト滞在時間 \(Y\)」「ある年の平均気温 \(X\) とアイスクリームの売り上げ \(Y\)」など ── 観測されるのはペア \((X_1, Y_1), (X_2, Y_2), \ldots, (X_n, Y_n)\) のように対になった標本である。

複数の確率変数を扱うと，自然と次のような問いが浮かぶ：

  • \(X\) と \(Y\) はどう「関係」しているだろうか？ \(X\) が大きいときに \(Y\) も大きい傾向があるだろうか？
  • \(X\) の値を知ったときに \(Y\) の予測は変わるだろうか？

こうした問いに答えるために，本ノートでは 相関 と 独立 という 2 つの概念を導入する。相関のない状態（無相関）は，日常的な語感としては「独立」に似た印象を与えるが，両者は同じではない。

  • 独立 \(\Rightarrow\) 無相関 ── 独立ならば必ず無相関。対偶をとると，「相関があるならば独立ではない」
  • 無相関 \(\nRightarrow\) 独立 ── 無相関だからといって独立とは限らない

両者は非対称な関係にあり，独立は無相関よりも強い概念 である。ここではまず「相関」を定義し，その幾何学的な意味を見たうえで「独立」との違いを明らかにする。

相関

2 つのデータ系列の 直線的な関係の強さ を表す指標として 相関 (correlation) がある。その前に，まず 2 つの量が同じ向きに動きやすいか，逆向きに動きやすいかを測る 共分散 (covariance) と呼ばれる量を導入しよう。

共分散

分布側（母集団）では，2 つの確率変数 \(X, Y\) の共分散は

\[ \begin{aligned} \mathrm{Cov}[X,Y] &= E\left[(X - E[X])(Y - E[Y])\right]\\[4pt] &= E[XY] - E[X]E[Y] \end{aligned} \]

で定義される。※ この値は分布を特徴づける母数で 母共分散 (population covariance) と呼ばれ，\(\sigma_{X,Y}\) とも表記する。ノート「母集団と標本」で見た \(E[X]\) と \(\mu_X\) の関係と同じで，\(\mathrm{Cov}[X,Y]\) は計算の記法，\(\sigma_{X,Y}\) はその値に与えた名前だ。

共分散の式変形については付録「確率変数の期待値と分散の式変形いろいろ」を参照。

期待値の計算の中に \(X\) と \(Y\) が同居している点に注意しよう。この期待値は，値の組 \((x, y)\) ごとの確率で重みを付けて計算する。離散型の確率変数の場合は次のようになる：

\[ \mathrm{Cov}[X,Y] = \sum_x \sum_y (x-E[X])(y-E[Y])\, P(X=x, Y=y). \]

ここに現れた \(P(X = x, Y = y)\) は，「\(X = x\) かつ \(Y = y\)」となる確率 ── すなわち 同時確率 である。同時確率はすでにノート「標本空間，事象，確率の初歩」で導入した。 \(P(X = x, Y = y)\) は，事象 \(\{X = x\}\) と事象 \(\{Y = y\}\) の積事象の確率 \(P\bigl(\{X = x\} \cap \{Y = y\}\bigr)\) を表す記法である。同時確率の分布を 同時分布 (joint distribution) と呼ぶ。 \(X\) と \(Y\) の両方に依存する量の期待値は，この同時分布に基づいて計算される。

連続型では和が積分に置き換わり，同時確率の役割は 同時確率密度関数 (joint probability density function) \(f_{X,Y}(x, y)\) が担う。これは値の組 \((x, y)\) のまわりの起こりやすさを表す確率密度で，1 変数の確率密度関数と同じく，領域で積分してはじめて確率になる。本ノートでは離散型を中心に話を進めるが，どの式も和を積分に，同時確率を同時確率密度に読み替えれば，そのまま連続型に適用できる。

一方，手元の \(n\) 個のデータ対 \((X_1, Y_1), \ldots, (X_n, Y_n)\) に対して同じ意味の量を計算したものが 標本共分散 (sample covariance) である。 \(\bar{X},\bar{Y}\) をそれぞれの標本平均とすると，

\[ S_{X,Y} = \frac{1}{n} \sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y}) \]

で定義される。

相関係数

共分散の値が正なら一方が平均より大きいときに他方も大きくなりやすく，負なら一方が大きいときに他方は小さくなりやすい。ただし共分散は \(X, Y\) の単位に依存するため，値そのものは比較しづらい。たとえば \(X\) が身長 [cm] で \(Y\) が体重 [kg] なら，共分散の単位は [cm・kg] というよくわからない量になる。そこで，共分散を \(X, Y\) の標準偏差で割って，物理次元をもたない \(-1\) から \(1\) の範囲に正規化した値※ が 相関係数 (correlation coefficient) である。分布側の相関係数は

\[ \rho_{X,Y} = \frac{\mathrm{Cov}[X,Y]}{\sqrt{V[X]}\sqrt{V[Y]}} = \frac{\sigma_{X,Y}}{\sigma_X\sigma_Y} \]

で定義され，母相関係数 (population correlation coefficient) と呼ばれる。標本側の相関係数は，標本共分散と標本標準偏差 \(S_X, S_Y\) を使って

\[ r_{X,Y} = \frac{S_{X,Y}}{S_X S_Y} \]

で定義され，標本相関係数 (sample correlation coefficient) と呼ばれる。分母の標準偏差が \(0\) でない場合，共分散が \(0\) であることと相関係数が \(0\) であることは同じだ。このとき「\(X\) と \(Y\) は 無相関 (uncorrelated) である」という。

なぜ共分散を各標準偏差で割ると \(-1\) から \(1\) の範囲に収まるのか，式変形で確認してみよう。いま適当な実数を \(t\) とおくと，分散の定義式から

\[ \begin{aligned} 0 &\leq V[X - tY]\\[4pt] &= t^2 V[Y] - 2t\,\mathrm{Cov}[X,Y] + V[X]\\[4pt] &= V[Y] \left(t - \frac{\mathrm{Cov}[X,Y]}{V[Y]}\right)^2 - \frac{\mathrm{Cov}[X,Y]^2}{V[Y]} + V[X] \end{aligned} \]

が成り立つ（1 行目から 2 行目への変形は，付録「確率変数の期待値と分散の式変形いろいろ」を参照）。これが任意の \(t\) で非負であるためには，右辺の平方完成の定数項が非負でなければならない。すなわち

\[ - \frac{\mathrm{Cov}[X,Y]^2}{V[Y]} + V[X] \geq 0 \quad\Longleftrightarrow\quad \mathrm{Cov}[X,Y]^2 \leq V[X] V[Y]. \]

よって

\[ -1 \leq \frac{\mathrm{Cov}[X,Y]}{\sqrt{V[X]}\sqrt{V[Y]}} \leq 1 \]

となる。

ここで \(X\) と \(Y\) を標準化した変数 \(Z_X = \frac{X - \mu_X}{\sigma_X}\) と \(Z_Y = \frac{Y - \mu_Y}{\sigma_Y}\) を考えてみよう。標準化によって平均はそれぞれ \(E[Z_X] = E[Z_Y] = 0\) になるから，

\[ \begin{aligned} \mathrm{Cov}[Z_X, Z_Y] &= E\left[(Z_X - E[Z_X])(Z_Y - E[Z_Y])\right]\\[6pt] &= E[Z_X Z_Y] = \frac{E[(X - \mu_X)(Y - \mu_Y)]}{\sigma_X \sigma_Y}\\[4pt] &= \frac{\sigma_{X,Y}}{\sigma_X \sigma_Y} = \rho_{X,Y} \end{aligned} \]

が成り立つ。つまり，相関係数とは，標準化した変数どうしの共分散 に他ならない。

先ほどは共分散を標準偏差で割って正規化したが，先に変数を標準化してから共分散を計算しても，同じ量にたどり着く。位置とスケールをそろえてから「同じ方向に動く度合い」を測り直したものが相関係数というわけだ。標準化した変数はいずれも物理次元をもたないから，それらの共分散である相関係数も物理次元をもたないことが，この見方からもわかる。

ベクトルに見立てたデータ列の内積が 0

次は，手元のデータ系列を対象とした標本相関係数 \(r_{X,Y}\) について考えてみよう。データ系列 \(X = (X_1, X_2, \ldots, X_n)\) は \(n\) 次元空間のベクトルと見なすことができる。そこで先ほどと同じように，各成分に標本版の標準化をほどこした 標準化ベクトル (standardized vector) を

\[ \widetilde{X} = \left(\frac{X_1 - \bar{X}}{S_X},\; \frac{X_2 - \bar{X}}{S_X},\; \ldots,\; \frac{X_n - \bar{X}}{S_X}\right) \]

と定めよう（\(Y\) 側も同様に \(\widetilde{Y}\) を定義する）。するとベクトルの内積は

\[ \begin{aligned} \langle \widetilde{X},\, \widetilde{Y} \rangle &= \sum_{i=1}^{n} \frac{(X_i - \bar{X})(Y_i - \bar{Y})}{S_X S_Y} \\[6pt] &= \frac{n S_{X,Y}}{S_X S_Y} = n\, r_{X,Y} \end{aligned} \]

と計算できる。和の中身の分子は標本共分散 \(S_{X,Y}\) の定義式に現れる項そのもので，その総和は \(n S_{X,Y}\) になる。また，標準化ベクトルのノルムは，データの中身によらずどちらも \(\sqrt{n}\) になる。※ したがって，2 つの標準化ベクトルのなす角を \(\theta\) とすると

\[ \cos\theta = \frac{\langle \widetilde{X},\, \widetilde{Y} \rangle}{\|\widetilde{X}\|\, \|\widetilde{Y}\|} = \frac{n\, r_{X,Y}}{\sqrt{n}\,\sqrt{n}} = r_{X,Y} \]

となり，相関係数は \(\cos\theta\) に等しい。この結果は相関係数が必ず \(-1\) から \(1\) の間に収まるという事実と整合している。

  • \(r_{X,Y} = 1 \quad \to \quad\) 2 つのベクトルが同じ向き ── 完全な 正の相関 (positive correlation)
  • \(r_{X,Y} = 0 \quad \to \quad\) 2 つのベクトルが直交 ── 無相関 (uncorrelated; zero correlation)
  • \(r_{X,Y} = -1 \quad \to \quad\) 2 つのベクトルが逆向き ── 完全な 負の相関 (negative correlation)

言い換えると，無相関であることは，標準化したデータベクトルどうしが幾何学的に直交していること に他ならない。

標準化ベクトル \(\widetilde{X}\) のノルムを計算してみよう（\(\widetilde{Y}\) も同様）： \[ \begin{aligned} \|\widetilde{X}\| &= \sqrt{\sum_{i=1}^{n} \left(\frac{X_i - \bar{X}}{S_X}\right)^2} \\[6pt] &= \frac{1}{S_X}\sqrt{\sum_{i=1}^{n} (X_i - \bar{X})^2} \\[6pt] &= \frac{1}{S_X}\sqrt{n S_X^2} = \sqrt{n}. \end{aligned} \]

独立

次に 独立 (independence) について考えよう。もし 2 つの確率変数が独立ならば，片方の値がわかったとしても，もう片方の値の予測精度を上げることはできない。ノート「ベイズの定理」では，データ（一方の事象）を得ることで仮説（もう一方の事象）の予測精度を上げられる ── つまり確率分布が変わる ── ことを見たが，そのような更新がそもそも起こらないのが「独立」という関係である。これを数式で表現すれば，独立とは，どの値の組 \((x, y)\) についても

\[ P(X = x \mid Y = y) = P(X = x) \]

が成り立つことである。左辺は「\(Y = y\) のとき \(X = x\)」となる確率 ── すなわち 条件付き確率 である。条件付き確率もすでにノート「標本空間，事象，確率の初歩」で導入済みだ。 \(P(X = x \mid Y = y)\) は，事象 \(\{Y = y\}\) が確定した状況における事象 \(\{X = x\}\) が起こる確率である。これが \(Y\) とは無関係の \(P(X = x)\) に等しいことから，この等式は「\(Y\) の値を知っても \(X\) の確率分布は変わらない」と読める。

さらに，両辺に \(P(Y = y)\) をかけると，条件付き確率の定義から左辺は同時確率 \(P(X = x, Y = y)\) に等しいので，

\[ P(X = x, Y = y) = P(X = x) P(Y = y) \]

が導かれる。これは 同時確率がそれぞれの確率の積に等しい という形をしており，2 つの確率変数が独立であることの典型的な表現 である。しかも，この積の形は \(X\) と \(Y\) について対称だ。 \(X\) と \(Y\) の立場を入れ替えて，同時確率を \(P(X = x)\) で割り直せば

\[ P(Y = y \mid X = x) = P(Y = y), \]

すなわち「\(X\) の値を知っても \(Y\) の確率分布は変わらない」も成り立つ。独立は対称な関係である。

この積の形の表現は 3 つ以上の確率変数が互いに独立である場合も同様で，たとえば \(n\) 個の確率変数 \(X_1, X_2, \ldots, X_n\) が互いに独立であるとは，どの \(x_1, x_2, \ldots, x_n\) についても

\[ \begin{aligned} &P(X_1 = x_1, X_2 = x_2, \ldots, X_n = x_n) \\ &\quad = P(X_1 = x_1)P(X_2 = x_2) \cdots P(X_n = x_n) \end{aligned} \]

が成り立つ関係である。

連続型の確率変数については，先ほど述べたとおり，確率を確率密度に置き換えればよい。条件付き確率にあたるものは 条件付き確率密度関数 (conditional probability density function)

\[ f_{X \mid Y}(x \mid y) = \frac{f_{X,Y}(x, y)}{f_Y(y)} \]

である。これは \(Y = y\) という条件のもとでの \(X\) の確率密度関数で，「同時確率を条件側の確率で割る」という条件付き確率の定義と同じ形をしている。あとは離散型とまったく同じ道筋で，独立の条件は \(f_{X \mid Y}(x \mid y) = f_X(x)\) あるいは \(f_{Y \mid X}(y \mid x) = f_Y(y)\)，そこから導かれる積の形は \(f_{X,Y}(x, y) = f_X(x)\, f_Y(y)\) となる。3 つ以上の場合も同様である。

独立は無相関と似た概念だが，冒頭で述べたとおり，より強い条件である。2 つの確率変数が独立ならばそれらは必ず無相関だが，無相関だからといって独立とは限らない。両者の違いを，以下では具体例で見ていこう。

相関 0 でも独立ではない例

次の 4 組のデータを考えよう：

相関 0 だが独立でない 4 組のデータ
\(i\)1234
\(X_i\)\(-2\)\(-1\)\(1\)\(2\)
\(Y_i\)\(4\)\(1\)\(1\)\(4\)

これは \(Y_i = X_i^2\) という関係にあるデータである。 \(Y\) は \(X\) から完全に決まっている（予測できる）ので，明らかに \(X\) と \(Y\) は独立ではない。それでも相関は \(0\) になる。実際に計算してみよう。

まず標本平均を求めて

\[ \begin{aligned} \bar{X} &= \frac{-2 - 1 + 1 + 2}{4} = 0, \\[6pt] \bar{Y} &= \frac{4 + 1 + 1 + 4}{4} = 2.5. \end{aligned} \]

これらを用いて標本共分散を計算すると

\[ \begin{aligned} S_{X,Y} &= \frac{1}{4} \sum_{i=1}^{4} (X_i - 0)(Y_i - 2.5) \\[6pt] &= \frac{1}{4} \left[ (-2)(1.5) + (-1)(-1.5) + (1)(-1.5) + (2)(1.5) \right] \\[4pt] &= \frac{1}{4} \left[ -3 + 1.5 - 1.5 + 3 \right] = 0 \end{aligned} \]

となる。すなわち相関係数 \(r_{X,Y} = 0\) である。

\(X\) と \(Y\) のあいだには \(Y = X^2\) という明白な（二次の）関係があるのに，相関はピタリと \(0\) になってしまう。相関は \(X\) そのものと \(Y\) そのものの直線的な関係（線形関係）しか捉えられない ことを示す例である。

視覚的な例 ── Datasaurus

もうひとつ有名な例として，Alberto Cairo が 2016 年に作成した Datasaurus※ を紹介しよう。これは 散布図 (scatter plot) ── 対になったデータを平面上の点として描いた図 ── を描くと恐竜の輪郭になる 142 点からなる \((X,Y)\) のデータセットで，相関係数は \(r_{X,Y} \approx -0.06\) と「ほぼ無相関」である。しかし \(X\) を知れば \(Y\) の取りうる範囲は強く制約され，散布図には相関係数だけでは捉えられない明確なパターン（非線形構造）が見える。

このように，相関係数がほぼゼロでも，変数間に強い構造が潜んでいることがある。複数の確率変数間の関係は，平均や分散，相関係数といった 要約統計量 (summary statistic) だけで判断せず，散布図を描いて構造を確かめることが重要である。

Alberto Cairo, Download the Datasaurus: Never trust summary statistics alone; always visualize your data (2016)。のちに Justin Matejka と George Fitzmaurice が同じ統計量をもつ 12 個の異なる形のデータセットを生成し，Datasaurus Dozen として発表している (Matejka & Fitzmaurice, CHI 2017)。

任意の関数で変換しても直交 ＝ 独立

では「独立」を幾何学的にどう表現できるだろうか？

鍵は \(X, Y\) をそのまま使うのではなく，任意の関数 \(f, g\) で変換した \(f(X), g(Y)\) についても常に無相関になるかどうか を問うことである。

たとえば \(f(X) = X^2,\ g(Y) = Y\) として，先の \(n=4\) の例から新しいデータ系列 \((f(X_i), g(Y_i))\) を作成し，相関を計算してみよう。 \(X^2\) の値は \(4, 1, 1, 4\) で平均は \(2.5\)，\(Y\) の値もまったく同じで \(4, 1, 1, 4\) で平均 \(2.5\) になるから，\(f(X)\) と \(g(Y)\) の標本共分散は

\[ \begin{aligned} S_{f(X),g(Y)} &= \frac{1}{4} \sum_{i=1}^{4} (X_i^2 - 2.5)(Y_i - 2.5) \\[6pt] &= \frac{1.5^2 + 1.5^2 + 1.5^2 + 1.5^2}{4} \\[4pt] &= 2.25 \end{aligned} \]

と，今度は \(0\) ではなくなった。 \(X\) そのものと \(Y\) そのものは無相関だが，\(X^2\) と \(Y\) は相関がある。これが「相関 \(0\) だが独立ではない」の正体である。

一般に，「独立」とは次のように特徴づけられる：

\[ \begin{aligned} &X \text{ と } Y \text{ が独立}\\ &\quad \iff \text{任意の関数 } f, g \text{ について } f(X) \text{ と } g(Y) \text{ が無相関}^\text{※} \end{aligned} \]
厳密には，ここでいう「任意の関数」とは期待値や共分散が発散してしまわないような十分広い関数クラスに限って考える。

まとめ

今回見た 2 つの概念を，ベクトルの言葉で並べてみよう。直交しているかどうかだけを見るなら，標準偏差で割る必要はなく，それぞれの平均を引いて中心化すれば十分である：

  • 無相関 ── \(X\) と \(Y\) を中心化して得られる 1 組 のベクトルが直交している。
  • 独立 ── 任意の \(f,g\) について，\(f(X)\) と \(g(Y)\) を中心化して得られる あらゆる組 のベクトルが直交している。

独立とは，あらゆる関数変換をほどこしても中心化した後の直交性が保たれるという 無限個の直交条件の束 を意味する。この視点に立つと，「独立ならば無相関」はすぐにわかるし，逆が一般には成り立たないことも理解できるだろう。

雑談

疑似相関

疑似相関 (spurious correlation) という言葉がある。面白おかしく語られる例として，Tyler Vigen の「Spurious Correlations」シリーズには「ニコラス・ケイジの年間映画出演数 vs プールでの溺死者数」（1999〜2009 年で \(r \approx 0.66\)）のような高い相関の例が大量にカタログ化されている。「詐欺師は数字で嘘をつく」とはよく言ったもので，データを切り抜けば，本来は無関係な 2 つのデータ系列にも高い相関は意外と簡単に見つけられるものだ。

ただ，疑似相関と呼ばれるものは，「疑似」ではなく統計量としては実際に高い相関を示している点に注意 ── それが「因果関係を意味しない」，あるいは「都合よく切り取ったデータの上でだけ成り立つ」という意味で「疑似」と呼ばれるのであって，その切り取られたデータに相関がないという意味ではない。

雨ごいは雨と独立か？

ある日の午前中に雨が降ったかどうかを確率変数 \(X\)，その日の午後に村人が雨ごいをしたかどうかを確率変数 \(Y\) としよう。さすがの雨ごいも，過去の天気までは変えられない。そこでつい，「雨ごいをしてもしなくても，午前中の天気そのものは変わらない」と考えて，\(P(X = x \mid Y = y) = P(X = x)\) と書きたくなる。これが成り立つなら，独立の対称性から

\[ P(Y = y \mid X = x) = P(Y = y), \]

すなわち「午前中の天気を知っても，午後に雨ごいをする確率は変わらない」も成り立つはずである。しかし，午前中に雨が降れば午後の雨ごいはせず，降らなければするのなら，午前の天気で雨ごいをする確率は明らかに変わる。何がおかしいのだろうか？

混同したのは，「午後の雨ごいが午前の天気を変えない」ことと，「午後の雨ごいを観察しても午前の天気についての推測が変わらない」ことだ。条件付き確率 \(P(X = x \mid Y = y)\) が表すのは，雨ごいをするかしないかを決めた場合の午前の天気ではなく，実際の行動が \(y\) だった日を後から振り返ったときの \(X = x\) の割合である。村人が午前の天気に応じて行動を決めるなら，雨ごいをしたという情報から「午前中は雨が降らなかったらしい」と推測できる。つまり，そもそも \(P(X = x \mid Y = y) = P(X = x)\) が成り立っていない。雨ごいの霊験ではなく，村人の判断が \(X\) と \(Y\) を結びつけているのである。

もし午後に雨ごいをするかどうかを，午前の天気とは無関係なコイントスで決めるなら，\(X\) と \(Y\) は独立になるだろう。統計的な独立は，どちらがどちらの原因かを述べるものではなく，一方の値を知っても他方の確率分布が変わらないという対称な関係である。
